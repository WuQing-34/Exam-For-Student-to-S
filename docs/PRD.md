# PRD：在线考试系统

- **文档版本**：v1.0
- **创建日期**：2026-05-20
- **产品负责人**：许清楚（产品经理）
- **项目名称**：`online_exam_system`
- **技术栈**：Vite + React + MUI + Tailwind CSS（前端）

---

## 1. 产品目标

1. **自动化考核流程**：让用户（学生/家长）在 Web 端独立完成考核并自动获得评分，减少人工判卷成本。
2. **精准筛选 S 班学员**：销售/辅导老师可在管理后台查看考试数据，快速筛选得分 ≥ 满分 60% 的用户，作为 S 班招募依据。
3. **高效的试卷与用户管理**：支持批量导入用户、Excel/Word 格式上传试卷、快速分配试卷，覆盖初一至初三多年级、多科目场景。

---

## 2. 用户角色定义

| 角色 | 描述 | 主要权限 |
|------|------|----------|
| **Administrator** | 系统管理员，负责试卷管理和全局配置 | 全部管理端功能，含试卷上传 |
| **短期班辅导（销售/辅导老师）** | 负责导入用户、分配试卷、查看考试数据 | 用户管理、分配试卷、考试数据查看（不含试卷上传） |
| **考生（学生/家长）** | 通过孩子姓名 + 年级 + 手机号登录，在用户端完成答题 | 查看已分配试卷、完成答题、查看分数 |

## 4. 页面结构 / UI 设计说明

### 4.1 管理端页面

---

#### 4.1.1 注册页 `/admin/register`

**字段：**
- 姓名（必填，文本输入）
- 邮箱前缀（必填，文本输入，不含 @domain 部分）
- 身份（必填，下拉：短期班辅导 / Administrator）
- 密码（必填，需同时含字母和数字，8 位以上）
- 确认密码（必填）

**交互：**
- 密码校验实时提示；提交时若密码不合规则，显示具体错误信息
- 注册成功后跳转登录页

---

#### 4.1.2 登录页 `/admin/login`

**字段：**
- 邮箱前缀
- 密码

**交互：**
- 失败提示："邮箱或密码错误"
- 登录成功后根据角色跳转首页

---

#### 4.1.3 管理首页（侧边栏导航）

**导航菜单：**
- 试卷管理（仅 Administrator 可见）
- 用户管理
- 分配试卷
- 考试数据

---

#### 4.1.4 试卷管理页 `/admin/papers`

**列表字段：** 试卷名称、年级、科目、题目数量、总分、上传时间、操作（预览 / 删除）

**上传试卷弹窗：**
- 文件上传（拖拽或点击，支持 .xlsx / .xls / .docx）
- 年级选择（必填）
- 科目选择（必填）
- 上传后系统解析：显示识别到的题目数量和题型分布，供确认
- 若解析失败，显示错误原因并允许重新上传

---

#### 4.1.5 用户管理页 `/admin/users`

**列表字段：** 姓名、手机号、年级、科目、已分配试卷数、操作（编辑 / 删除）

**搜索/筛选：** 按姓名关键词、按年级

**批量导入弹窗：**
- 下载模板按钮（.xlsx 格式，含示例数据）
- 文件上传
- 导入预览：显示解析的行数，出错行高亮提示

**编辑弹窗字段：**
- 孩子姓名、手机号、年级（单选）、科目（多选 Checkbox）

---

#### 4.1.6 分配试卷页 `/admin/assign`

**布局：**
- 左侧：用户列表（支持多选 Checkbox），可按年级、科目筛选
- 右侧：选择要分配的试卷（下拉 + 预览按钮）

**交互：**
- 勾选用户后，点击"分配"按钮，弹出确认弹窗，显示已选用户数和试卷名称
- 批量分配完成后 Toast 提示成功/失败数量

---

#### 4.1.7 考试数据页 `/admin/exams`

**列表字段：** 用户姓名、年级、科目、试卷名称、得分 / 满分、得分率、考试时长、状态、操作（查看详情 / 导出 Word）

**筛选区：**
- 年级下拉
- 得分率区间输入（如：60% ~ 100%）
- 状态下拉（未开始 / 答题中 / 已完成）

**试卷详情抽屉/弹窗：**
- 显示每道题：题目、考生答案、参考答案、得分 / 该题满分
- 底部"导出 Word"按钮

---

### 4.2 用户端页面

---

#### 4.2.1 用户登录页 `/login`

**字段：**
- 孩子姓名
- 年级（下拉：初一 / 初二 / 初三）
- 手机号

**交互：**
- 三者同时匹配才能登录
- 匹配失败：提示"未找到您的信息，请联系辅导老师导入"
- 登录成功跳转试卷列表页

---

#### 4.2.2 试卷列表页 `/exams`

**列表字段：** 试卷名称、科目、年级、状态（未开始 / 已完成）、得分（已完成时显示）

**无试卷状态：** 插图 + 提示"请联系辅导老师分配试卷"

---

#### 4.2.3 答题页 `/exams/:id/answer`

**布局（响应式）：**
- 顶部：题号进度（第 x 题 / 共 y 题）
- 中部：题目内容 + 作答区
  - 选择题：单选/多选按钮（A/B/C/D）
  - 填空题：文本输入框
  - 简答题：多行文本框（Textarea）
- 底部：上一题 / 下一题 按钮；最后一题显示"提交"按钮

**提交流程：**
1. 点击"提交" → 检查未答题
2. 若有未答题 → 弹窗"您有未答完的题，是否确认交卷？" → 是（提交）/ 否（返回继续）
3. 全部已答 → 直接提交
4. 提交后显示 loading："系统正在自动判分中，请稍等...."
5. 判分完成 → 全屏结果页："您的分数是：xx 分"

---

#### 4.2.4 结果页 `/exams/:id/result`

**展示内容：**
- 得分（大号字体）
- 满分
- 得分率
- 返回首页按钮

## 6. 非功能性需求

### 6.1 兼容性

- 支持主流移动端浏览器（iOS Safari、Android Chrome）
- 支持 PC 端 Edge / Chrome 最新两个版本
- 响应式设计，断点：手机（< 768px）/ iPad（768px ~ 1024px）/ 桌面（> 1024px）

### 6.2 安全性

- 管理端与用户端接口均需鉴权（JWT 或 Session）
- 密码存储使用 bcrypt 哈希，不可逆
- 试卷答案字段在用户端接口中不返回（防止作弊）
- 防止重复提交：提交后接口加幂等校验

### 6.3 性能

- 试卷解析（Excel/Word）应在 10 秒内完成
- 批量导入用户支持单次 ≥ 500 条

### 6.4 数据导出

- Word 导出使用服务端生成（如 python-docx 或 docxtpl），确保排版一致

### 6.5 可用性

- 判分逻辑：选择题和填空题自动比对答案（忽略大小写、首尾空格）；简答题本期自动判为满分或 0 分（待确认）
